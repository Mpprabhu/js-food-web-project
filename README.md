# 🍴 Forkify Web App

Welcome to the **Forkify Web App**! This project helps users **search for recipes using ingredients**, view detailed cooking instructions, and manage bookmarks and a shopping list.
 
🔗 **Live Website:** [Click Here](https://forkify-food-project-prabhu.netlify.app/)  

---

## 🚀 Features

✅ **Search Recipes** - Find recipes by searching for ingredients.  
✅ **Recent Searches** - View your last searched ingredients.  
✅ **Bookmark Recipes** - Save favorite recipes for easy access.  
✅ **Shopping List** - Add recipe ingredients to your shopping list.  
✅ **Pagination** - Browse through multiple search results.

---

## 🛠️ Technologies Used

- **HTML, CSS, JavaScript** - Frontend UI & interactivity
- **ES6 Modules** - Code organization
- **LocalStorage** - Save bookmarks & recent searches
- **API Fetching** - Retrieve recipes from a public API
- **MVC Pattern** - Maintainability and clean code

## 🌟 How It Works

### 1️⃣ Searching for a Recipe

1. Enter an **ingredient** (e.g., `chicken`, `tomato`) in the search bar.
2. Click **Search** to fetch recipes.
3. If recipes exist, they will be displayed with images, titles, and publishers.
4. If **no recipes are found**, an alert message will appear (`No recipes found`).

### 2️⃣ Viewing Recipe Details

1. Click on a **recipe** from the search results.
2. The page will show **cooking time, servings, and ingredients**.

### 3️⃣ Bookmarking a Recipe

1. Click the **Bookmark Icon** 🔖 on a recipe to save it.
2. Access saved recipes in the **Bookmarks** section.

### 4️⃣ Managing Recent Searches

1. The **Recent Searches** section stores past searches.
2. **Invalid searches (no results)** are automatically **ignored**.

### 5️⃣ Adding Ingredients to the Shopping List

1. Select a recipe and click **Add to Shopping List** 🛒.
2. The list updates with the required ingredients.
3. Remove items manually if no longer needed.
